- **Nit 2**: `cli.py:44-46` 在函数内 import `os` + `LLMRouter`,建议移到顶部,与其他 import 一致。优先级 low
- **Nit 3**: `parsers.py` 接受 `--log-type` 默认 `sshd` —— S1 指令里说 "cli 加 --log-type",已实现。但 S2 加关联检测时,默认 log_type 应让 user 显式选(避免误判 SSH 关联到 Nginx 上)。优先级 low
